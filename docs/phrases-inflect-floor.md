# Inflect-annotation floor — triage of `no-matching-cell` / `no-paradigm` (#439)

_Generated by `scripts/triage-inflect.mjs` + the categoriser for #439. Regenerate after any
change to `public/vocab/*.yml`; counts here reflect the state when this file was committed._

The exhaustive-annotation effort (#359) annotates every usage sentence whose target carries an
inflected form. This file triages the **residue the matcher cannot annotate** into three
dispositions:

- **FLOOR** — genuinely cannot carry an `inflect:` annotation. The target is in its citation
  form (verb infinitive in the compound future / after a modal), a derived adverb, an
  indeclinable possessive, or a different (compound) word. These bound what "annotate
  everything" can mean and are correct to leave bare — they still serve the translation,
  listening and speaking drills.
- **FEATURE** — annotatable in principle, but needs matcher/data support that does not exist
  yet (short-form & comparative adjectives, multi-word lemmas, the `н`-prothesis pronoun forms,
  the quantity pronoun `ско́лько`). Handed forward as feature work.
- **DATA** — a data error to correct at source: the example does not contain the lemma, uses an
  aspect-partner form, or the stored declension is sparse/malformed.

The 89 verbs that used their imperative in a usage sentence but stored no imperative block are
handled separately (imperative forms harvested from the sentences and added to the paradigm);
one multi-token sentence (`ло́коть`) was annotated directly.
